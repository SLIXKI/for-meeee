Verifying a build

Download it, then run sha256sum asheo-latest.zip and compare against the hash listed above. If they differ, the file is not what was published — don't run it. Older builds stay listed for reference, but only the current release is authorized to run: Asheo verifies its own signed file manifest at startup, and a superseded build fails that check.
