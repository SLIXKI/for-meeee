Install

  1. Unzip it into a folder you intend to keep — Chrome loads the extension from that folder, so deleting it uninstalls Asheo.
  2. Open chrome://extensions
  3. Turn on Developer mode (top right).
  4. Click Load unpacked and select the unzipped folder.

Updating

  1. Download the new .zip and unzip it over the same folder.
  2. Back on chrome://extensions, press Reload on the Asheo card.
